# Logo assets

- Microsoft_Azure.png — Azure product icon, official Microsoft Azure blog artwork (dark background).
  https://azure.microsoft.com/en-us/blog/a-fluent-new-look-for-the-azure-icon/
- Azure_Marketplace.svg / .png — Marketplace product icon from the official Microsoft Azure architecture icon package.
  https://learn.microsoft.com/en-us/azure/architecture/icons/
- Kyndryl.svg / .png — official Kyndryl website logo. “Kindryl” was interpreted as Kyndryl.
  https://www.kyndryl.com/etc.clientlibs/kyndrylprogram/clientlibs/clientlib-site/resources/images/logo-kyndryl-red.svg
- NVIDIA_Horizontal.svg / .png and NVIDIA_Vertical.svg / .png — official NVIDIA logo formats.
  https://www.nvidia.com/en-gb/about-nvidia/legal-info/logo-brand-usage/
- AWS.png — original 1254 × 750 PNG from Amazon's official press center.
  https://press.aboutamazon.com/logos

SVG originals are retained. PNG copies of SVGs preserve transparency and proportions. The Azure PNG retains the background in Microsoft's original artwork. The original Microsoft icon ZIP is retained in Sources.
